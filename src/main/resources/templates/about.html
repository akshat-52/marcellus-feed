About Marcellus
A developer's knowledge base and algorithmic journey

What is Marcellus?

Marcellus is a lightweight, high-performance developer knowledge base and discussion engine built from scratch with Java and Spring Boot. Designed for engineers who prefer clean flat-file Markdown over bloated databases, it serves as a centralized hub for logging code snippets, documenting system architecture, and tracking algorithmic problem-solving milestones.

Tech Stack

  • Backend: Java & Spring Boot
  • Templating & Rendering: Thymeleaf & CommonMark (Markdown parser)
  • Data Layer: Flat-file Markdown storage with JSON interaction counters
  • Deployment: Continuous Deployment via Render & GitHub
